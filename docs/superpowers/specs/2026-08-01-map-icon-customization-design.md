# Pastoral 地图农牧图标自定义与手机键盘布局设计

**日期：** 2026-08-01
**状态：** 已获用户批准
**范围：** 地图/农牧/种子/畜牧图标预设与本地自定义、右键/长按替换、手机沉浸软键盘布局、迁移参考资料去源码依赖

## 1. 目标

1. 扩充当前 24×24 手绘 SVG 图标预设，覆盖常见地图、作物、种子和畜牧类型。
2. 允许玩家上传 PNG、JPG、WebP 或 SVG 到浏览器 IndexedDB 的“我的图标”库，并在多个目标间复用。
3. 桌面右键、手机长按打开统一图标选择器；键盘用户可通过可聚焦目标的上下文菜单键或 Shift+F10 操作。
4. 地图和农田支持坐标级覆盖；同名地块可选共享；种子图鉴和同名作物默认共享；畜牧按名称共享。
5. 手机沉浸模式使用 VisualViewport 与正常文档流稳定 HUD、正文、输入框、状态栏和快捷按钮；软键盘打开时隐藏状态/快捷栏。
6. 将 `迁移参考资料/README.md` 改成不依赖 Pastoral 原始 JS/CSS/HTML 的自包含迁移手册，仅以接口切片作为外部契约资料。

## 2. 非目标

- 不把图片或映射写入 MVU、聊天消息或模型提示词。
- 不实现云同步、导入导出图标包、跨浏览器同步或动态图标。
- 不更改地图探索、农事、种子或畜牧的业务数据结构。
- 不改变桌面双页、手机经营/剧情单页切换和第二 API 流程。
- 不用绝对坐标把输入框或快捷栏钉在软键盘上方。

## 3. 架构与模块边界

### 3.1 `js/icons.js`

- 保留 `Icon.get()`、`Icon.render()`、`Icon.set()` 的同步系统 SVG 能力。
- 扩充手绘预设及元数据目录（名称、分组、搜索关键词）。
- 新增可替换目标的统一渲染入口，使系统 SVG 与个人图片使用同一图标容器契约。

### 3.2 `js/assets.js`

将现有头像 IndexedDB 仓库升级为通用本地资产仓库：

- `staff-avatar`：保持现有行为。
- `custom-icon`：Blob、名称、MIME、更新时间。
- `icon-binding`：目标键到图标 ID 的映射。

图片 Blob 和映射都在 IndexedDB；MVU 和 `mrfz_settings` 不承担图片偏好。数据按当前角色卡/独立预览 scope 隔离。

### 3.3 新增 `js/icon-picker.js`

负责：

- 预设/个人图标目录；
- 图标解析优先级；
- 右键与长按手势；
- 选择器对话框、上传、重命名、删除、恢复默认；
- 异步 Blob URL 加载与节点局部刷新；
- 映射变化通知。

该模块不理解地图或农牧内部结构；调用方传入规范化目标描述和候选绑定键。

### 3.4 `js/render.js`

地图、农田、种子和畜牧渲染时提供：

- 默认系统图标；
- 当前目标键；
- 可选共享键；
- 可读名称与应用范围；
- 可替换语义与可聚焦属性。

MVU 重绘后根据 IndexedDB 映射重新解析，不保存 DOM 引用为长期状态。

### 3.5 `js/app.js` 与 `css/layout.css`

负责 VisualViewport、高度 CSS 变量、键盘状态类和手机沉浸布局，不把图标业务混入布局模块。

## 4. 图标预设与个人库

### 4.1 系统预设

扩充下列类别：

- 地图：森林、草原、丘陵、山峰、河流、湖泊、海岸、沼泽、洞穴、矿区、遗迹、村落、道路、桥梁、营地、神殿、花田、果林、荒漠、雪地。
- 作物与种子：谷物、稻麦、玉米、根茎、叶菜、豆类、香草、蘑菇、花卉、果实、浆果、魔法植物、种子袋、幼苗、成熟、枯萎。
- 农牧：普通农田、魔法农田、荒地、已开垦、种植中、成熟、鸡、鸭、牛、羊、猪、蜂箱、牧场、禽舍、畜棚、饲料槽、堆肥、待收取产出。

所有预设沿用 24×24、`currentColor` 和当前手绘线稿视觉。

### 4.2 上传约束

- 接受 PNG、JPEG、WebP、SVG。
- 单文件最大 2 MiB，个人库最多 100 个。
- 上传后验证 MIME 与可解码性；拒绝格式伪装或损坏文件。
- SVG 仅作为 Blob 图片 URL 加载，不把源码注入 `innerHTML`。
- 不接受 GIF 等动画格式。
- 默认名称取去扩展名后的文件名，可重命名。

### 4.3 图片显示

自定义图片在方形容器中使用 `object-fit: contain`。异步 URL 未就绪或加载失败时继续显示系统默认图标，不出现空白，也不阻塞面板渲染。

## 5. 映射键与优先级

目标和共享键由长度受限的规范化字符串组成。名称只做 trim 与连续空白压缩，不做大小写折叠或模糊匹配。

### 5.1 地图

- 坐标键：`map:<x>,<y>`
- 同名键：`map-name:<规范化地块名或类型>`

优先级：

```text
坐标专属覆盖 > 同名共享覆盖 > 类型系统推断 > 通用地块图标
```

选择器默认仅当前坐标，可勾选“同时应用到所有同名地块”。

### 5.2 普通与魔法农田

- `farm:normal:<x>,<y>`
- `farm:magic:<x>,<y>`
- 作物共享键：`crop:<规范化作物名>`

优先级：

```text
田格专属覆盖
> 作物名称共享覆盖
> 田格状态预设（成熟/种植中/已开垦/荒地）
> 农田类型预设（普通/魔法）
> 系统兜底
```

有作物田格的选择器提供“仅当前田格”和“所有同名作物”，默认仅当前田格。

### 5.3 种子图鉴

种子卡与田格中的同名作物默认共享 `crop:<名称>`。从种子图鉴保存时直接应用于该种子和所有同名作物；田格专属覆盖仍优先。

### 5.4 畜牧

使用 `livestock:<规范化条目名>`，同名畜牧条目共享。名称变化视为新条目；旧映射保留以便名称恢复。

## 6. 替换交互与选择器

### 6.1 触发

- 桌面：目标右键。
- 手机：按住 550ms；指针移动超过 12px、取消、离开或滚动即取消。
- 长按成功后抑制随后一次 click，避免同时打开详情。
- 目标可聚焦并响应 `ContextMenu` 键或 Shift+F10。
- `aria-label`/提示文案说明“右键或长按更换图标”。

### 6.2 选择器

桌面为居中对话框，手机为底部抽屉，使用同一 DOM 结构：

- 当前对象说明；
- “系统预设 / 我的图标”标签；
- 至少 44×44px 的图标网格；
- 上传、重命名、删除；
- 当前目标适用的范围选项；
- 恢复系统默认、取消、保存。

要求：

- 原生按钮、清晰选中态、`aria-selected`、方向键导航；
- 打开时捕获焦点，Escape 关闭，关闭后归还焦点；
- 上传/删除异步动作显示忙碌状态；
- 空个人库有说明和上传入口；
- 反馈使用 toast 或内联状态，不使用 `alert()`。

### 6.3 删除语义

删除个人图标前显示引用数量。确认后删除 Blob 和所有指向该 ID 的绑定；受影响目标立即按下一优先级回退。删除不修改 MVU。

## 7. 手机沉浸与软键盘布局

### 7.1 正常布局

手机沉浸剧情页保持正常文档流：

```text
手机页签 → HUD → 正文/选项/请求状态 → 输入框 → 状态/快捷栏 → 安全区
```

- 书容器高度使用 `--mobile-viewport-height`。
- CSS 默认 `100dvh`，并有 `100vh` 回退。
- 支持 VisualViewport 时，JS 写入实时 `visualViewport.height`。
- 右页使用纵向 flex/grid；正文为 `flex:1; min-height:0; overflow:auto`。
- 输入框与 dock 不使用 fixed/absolute 定位。
- 输入框自动增高有上限，超过后内部滚动。
- dock 在手机沉浸下使用明确网格，不依赖任意 `flex-wrap`；按钮至少 44×44px。

### 7.2 键盘状态

监听 `visualViewport.resize/scroll`、`window.resize` 与输入焦点。只有输入框聚焦且可视高度显著小于布局视口时才添加 `.is-mobile-keyboard-open`，避免实体键盘误判。更新经 `requestAnimationFrame` 合并。

### 7.3 键盘打开

- HUD 保留并压缩为紧凑单行。
- 正文继续滚动并占用剩余空间。
- 输入框是布局中的底部锚点。
- 隐藏精力、压力与全部快捷按钮（烹饪、浇灌、小憩、归寝）。
- 仅保留正文、选项/请求状态、输入框和发送按钮。
- 关闭键盘后恢复 dock。
- 不在每次视口变化时强制滚到底部；只确保聚焦输入框进入可视区域。

### 7.4 触摸适配

触摸设备关闭 hover tooltip；页签、输入、发送和快捷按钮保留安全区、焦点态和 44px 目标。退出沉浸或切换页面时清理键盘状态并重新同步高度。

## 8. 错误与降级

- IndexedDB 不可用：系统预设与游戏功能继续工作，上传入口禁用并显示明确说明。
- Blob URL 失败：回退默认系统图标，只记录一次诊断。
- 单个绑定损坏或引用不存在：忽略该绑定并回退，不阻止其他图标加载。
- 映射写入失败：不更新内存最终状态，显示保存失败，可重试。
- `visualViewport` 不存在：使用 `100dvh` 与焦点 CSS 降级；仍不得绝对定位 dock。
- 个人图片仅在本地浏览器保存，清除站点数据会丢失；UI 中明确说明。

## 10. 测试与验收

### 10.1 图标资产与映射

- 上传四种允许格式；拒绝超大、损坏和不允许格式。
- 个人图标列举、重命名、复用、删除和引用清理。
- 地图坐标 > 同名 > 默认。
- 农田坐标 > 作物 > 状态/类型 > 默认。
- 普通/魔法农田同坐标不串联。
- 种子与同名作物共享；田格专属仍覆盖。
- 畜牧按名称共享。
- MVU 重绘和页面切换后覆盖保留。
- IndexedDB 不可用和损坏引用正确降级。

### 10.2 交互

- 右键、长按、ContextMenu 键和 Shift+F10 均可打开。
- 滚动/移动取消长按，成功长按不触发普通 click。
- 焦点陷阱、Escape、焦点归还、ARIA 和最小触控尺寸有效。
- 删除显示引用数并回退到下一优先级。

### 10.3 手机布局

- 手机沉浸 dock 不换行乱飞。
- VisualViewport 缩小时 CSS 高度同步。
- 键盘打开仅隐藏 dock，输入框与正文保持可见。
- 键盘关闭恢复 dock。
- 多行输入有上限；正文滚动不会被连续重置。
- 无 VisualViewport、桌面和非沉浸模式不回归。
