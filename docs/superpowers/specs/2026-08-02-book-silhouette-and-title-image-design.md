# 书本轮廓与标题背景图入口设计

**日期：** 2026-08-02  
**状态：** 已批准，待实施

## 1. 目标

修正酒馆内正式界面过度横向拉伸后书本形状不清晰的问题，同时为未来使用图床替换标题页场景背景预留一个稳定、易说明的入口。

本次只调整视觉布局和标题背景资源入口，不改变双页业务结构、内容数据、事件、滚动、移动页签或沉浸逻辑。

## 2. 已确认体验

### 2.1 桌面与平板

- 酒馆中的整体舞台继续铺满可用区域，不把整个界面缩成居中的窄卡片。
- 双页书本内部在最左和最右保留同色页缘，使外轮廓、圆角、纸张厚度、阴影和中央书脊共同形成完整书册形状。
- 页缘属于书本视觉结构，不表现为页面外部的大块黑边或普通容器空白。
- 普通酒馆模式与沉浸模式均保持这一书本轮廓；沉浸模式可以使用更紧凑的页缘，但不能让书页完全贴到外壳边缘。
- 双页继续严格等宽，现有内部滚动区域不变。

建议使用响应式内缩值，桌面范围约为 `clamp(16px, 2vw, 32px)`；最终数值应通过实际浏览器画面微调，而不是改变内容最大阅读宽度。

### 2.2 手机

- 手机不强制保留外侧页缘，单次显示完整的经营页或剧情页。
- 继续沿用现有移动页签、安全区、动态视口高度和内部滚动逻辑。
- 不为模拟书本轮廓牺牲手机正文宽度；只保留组件本身已有的必要内边距和圆角。

## 3. 布局实现边界

推荐使用“外壳铺满、页面内缩”的结构：

1. `.book` 仍作为铺满可用区域的书本外壳和阴影边界。
2. 桌面/平板通过外壳内边距或等价的逻辑属性，为左右页提供同色页缘。
3. `.page` 继续承担内容纸面、边框与圆角；中央 `.book__spine` 继续承担装订视觉。
4. 小于移动断点时移除额外页缘，避免双重缩进。
5. 不新增覆盖内容的交互伪层；若使用伪元素，只能用于 `pointer-events: none` 的纯装饰。

需要避免：

- 仅缩小整个 `.book` 的宽度并在外部制造大片空白；
- 让书页在桌面贴到 iframe 两侧，丢失书册外形；
- 修改 `page` 的等宽规则、移动单页选择规则或正文 `66–72ch` 阅读宽度；
- 用固定像素宽度导致中等尺寸设备溢出。

## 4. 标题页图床背景入口

### 4.1 范围

本次只为标题页与场景背景图预留入口，不覆盖：

- 书页纹理；
- 员工头像；
- 物品、建筑、地图或农田图标；
- 应用内图片上传器。

### 4.2 CSS 契约

在现有主题/设计令牌区域定义单一语义变量，例如：

```css
--title-scene-image: none;
```

标题页场景把该变量作为可选的最上层或适当层级背景图，并叠加现有渐变、暗角与可读性遮罩。默认 `none` 时，当前纯 CSS 山谷、山脉、湖面、旅店和萤火虫场景完整保留。

未来得到图床直链后，只需改为：

```css
--title-scene-image: url("https://example.com/pastoral-title.webp");
```

背景应采用：

- `background-size: cover`；
- 居中或由现有构图确定的焦点位置；
- 不影响标题、作者、开始按钮和链接的层级；
- 图片请求失败时仍能看到现有 CSS 场景和可读文字。

### 4.3 图床使用说明

实施完成后向用户提供以下操作说明：

1. 将横向场景图上传到支持 HTTPS 原图直链的图床或静态资源托管服务。
2. 推荐格式为 WebP；推荐画幅 16:9；建议至少 1920×1080，并控制体积以缩短酒馆内加载时间。
3. 复制直接返回图片内容的原图地址，而不是图床预览页面地址。
4. 在项目设计令牌文件中找到 `--title-scene-image`，将 `none` 替换为 `url("直链")`。
5. 运行构建脚本，生成新的自包含入口页面。外链图片本身不会嵌入 HTML，使用时需要网络可访问。

## 5. 可访问性与韧性

- 图片为纯装饰背景，不增加无意义的替代文本或可聚焦元素。
- 保留现有文字阴影、遮罩和颜色对比；实际接入图片时仍需检查 WCAG AA 可读性。
- 背景图加载不会阻塞标题内容和开始按钮显示。
- `prefers-reduced-motion` 行为不因静态背景入口改变。
- 移动端背景继续 `cover`，但标题内容不得横向溢出。

## 6. 测试与验收

### 6.1 自动测试

- 布局测试确认桌面/平板存在书本外侧页缘规则。
- 布局测试确认手机断点移除额外页缘。
- 保留双页等宽、移动单页切换、`100dvh`/安全区和正文阅读宽度断言。
- 标题测试确认 `--title-scene-image` 存在且默认值为 `none`。
- 标题场景规则确认使用该变量，并保留现有 CSS 背景作为回退。
- 构建后确认 `index.html` 与 `public/index.html` 一致。

### 6.2 实际画面

至少检查：

- 桌面酒馆普通模式：舞台铺满，左右页缘可见，书本形状完整；
- 桌面沉浸模式：仍有书形但不过度浪费宽度；
- 768px 左右的中等宽度：无溢出、无异常压缩；
- 375px 手机：额外页缘消失，经营页/剧情页各自完整占用宽度；
- 默认无图床 URL：原 CSS 标题场景不退化；
- 临时测试一个有效与一个失效图片 URL：有效图覆盖场景，失效 URL 仍有 CSS 回退和可读标题。

## 7. 非目标

- 不引入图床 SDK、上传凭据或 API Key。
- 不把远程图片下载并嵌入构建产物。
- 不修改本地 IndexedDB 图片系统。
- 不重构标题页 DOM、书页业务组件或宿主 iframe 生命周期。
- 不借本次布局修正处理无关视觉或业务问题。
